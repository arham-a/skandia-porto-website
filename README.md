# Skandia Porto website

Static maritime services website built with Astro 5 and Tailwind CSS 4.

## Local development

```sh
npm install
npm run dev
```

The development server runs at `http://localhost:4321` by default.

## Validation and production

```sh
npm run check
npm run build
npm run preview
```

The production build is written to `dist/` as a self-contained static site.

## Deployment

Pushes to `main` are automatically built and deployed to GitHub Pages:

https://arham-a.github.io/skandia-porto-website/
